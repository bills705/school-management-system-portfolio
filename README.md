# School Management System

A desktop-based School Management System built with Java Swing and MySQL. It helps schools manage academic, administrative and financial records from one centralized application.

## Project Overview

The system was designed for Kindergarten, Primary and Junior High School environments. It provides separate Admin and Teacher portals with role-based access to school functions.

## Main Features

- Secure Admin and Teacher authentication
- Password hashing and password recovery
- Student registration and academic enrollment
- Teacher registration and management
- Class, division and subject management
- Teacher, class and subject assignments
- Academic year and active-term management
- Student attendance management
- Continuous Assessment entry
- Examination score entry
- Configurable CA and examination percentages
- Flexible grading-scale configuration
- Automatic final-score and grade calculation
- Subject and overall student positions
- Student report cards and printable reports
- Teacher and headteacher comments
- Student promotion to the next class and academic year
- Fees assignment, payments, credits and receipts
- Student academic and payment history
- Parent SMS notifications using the Arkesel SMS API
- School information, logo and report customization

## Technologies Used

- Java
- Java Swing
- MySQL
- JDBC
- Apache Maven
- NetBeans IDE
- BCrypt password hashing
- Arkesel SMS API
- Git and GitHub

## User Roles

### Administrator

The administrator manages students, teachers, classes, subjects, academic years, fees, results, reports, school settings and teacher assignments.

### Teacher

Teachers can manage attendance, enter assessment and examination scores, view assigned classes and subjects, enter report comments, view results and print student reports.

## Security

- User passwords are stored as BCrypt hashes.
- Database credentials and API keys are stored in external configuration files.
- Sensitive configuration files and student photographs are excluded from this public portfolio.
- The complete production source code and database are maintained in a private repository.
